# MAX Robot – Communication

The `maxrobot_communication` repository is part of the MAX open-source robotics ecosystem developed by **Mensch Robotics Private Limited**.

This repository focuses on the communication architecture that enables data exchange and coordination between different computing and control units within the MAX Robot, including Jetson–Arduino communication.

It serves as a reference for understanding and developing communication systems within the MAX platform.

**Main Repository:** https://github.com/menschrobotics/maxrobot
